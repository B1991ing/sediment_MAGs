Folder scripts/Co-assembly:
megahit_omstrup_sediment.sh: The Ormstrup sediment fasta files were assembled using MEGAHIT.
megahit_sillebotten_sediment.sh: The Sillebotten sediment FASTA files were assembled using MEGAHIT.

Folder scripts/Individual Assembly:
metaSPAdes_assemble_1_8.sh: The Sillebotten sediment fasta files were assembled using metaSPAdes.
metaSPAdes_assemble_9_16.sh: The Ormstrup sediment fasta files were assembled using metaSPAdes.

Folder scripts/Binning_co/binny includes two scripts:
binny_omstrup_sediment.sh: Contigs co-assembled using MEGAHIT were binned using binny for the Ormstrup sediment samples.
binny_sillebotten_sediment.sh: Contigs co-assembled using MEGAHIT were binned using binny for the Sillebotten sediment samples.

Folder scripts/Binning_co/metabinner includes two scripts:
metabinner_omstrup_sediment.sh: For the Ormstrup sediment samples, contigs generated by co-assembly with MEGAHIT were binned using metabinner.
metabinner_sillebotten_sediment.sh: For the Sillebotten sediment samples, contigs generated by co-assembly with MEGAHIT were binned using metabinner.

Folder scripts/Binning_co/metawrap includes two scripts:
metawrap_binning_omstrup_sediment.sh: Contigs co-assembled using MEGAHIT were binned using metawrap for the Ormstrup sediment samples.
metawrap_binning_sillebotten_sediment.sh: Contigs co-assembled using MEGAHIT were binned using metawrap for the Sillebotten sediment samples.

Folder scripts/Binning_co/semibin includes two scripts:
semibin_omstrup_sediment.sh: For the Ormstrup sediment samples, contigs generated by co-assembly with MEGAHIT were binned using SemiBin.
semibin_sillebotten_sediment.sh: For the Sillebotten sediment samples, contigs generated by co-assembly with MEGAHIT were binned using SemiBin.

Folder scripts/Bin_refinement_co includes two scripts:
metawrap_bin_refinement_b3b_bms_sillebotten_sediment.sh: Bins generated by binny, MetaBinner, and SemiBin were refined using metawrap_bin_refinement in the Sillebotten sediment.
metawrap_bin_refinement_b3b_bsm_omstrup_sediment.sh: Bins generated by binny, MetaBAT2, and SemiBin were used as input to metawrap_bin_refinement in the Ormstrup sediment.

Folder scripts/Binning_individual/binny:
rawbam_1_24.sh: This script was used to generate a *_raw_unique_sort.bam file for each set of contigs individually assembled with metaSPAdes.
binny_1_24.sh: Contigs assembled individually from each lake sediment sample using metaSPAdes were binned using binny.

Folder scripts/Binning_individual/vamb:
vamb_binning_omstrup_sediment.sh: Contigs assembled individually from each lake sediment sample using metaSPAdes were binned using vamb in the Ormstrup sediment.
vamb_binning_sillebotten_sediment.sh: Contigs assembled individually from each lake sediment sample using metaSPAdes were binned using vamb in the Sillebotten sediment.

Folder scripts/dRep/dRep_co:
drep_vamb_binny_b3b_omstrup_sediment_norefinem.sh: For the Ormstrup sediment samples, bins generated by the three best-performing binners in the co-assembly workflow were dereplicated using dRep.
drep_vamb_binny_b3b_sillebotten_sediment_norefinem.sh: For the Sillebotten sediment samples, bins generated by the three best-performing binners in the co-assembly workflow were dereplicated using dRep.

Folder scripts/dRep/dRep_individual:
drep_vamb_binny_omstrup_sediment.sh: For the Ormstrup sediment samples, bins generated by Vamb and binny in the individual assembly workflow were dereplicated using dRep.
drep_vamb_binny_sillebotten_sediment.sh: For the Sillebotten sediment samples, bins generated by Vamb and binny in the individual assembly workflow were dereplicated using dRep.

Folder scripts/dRep:
drep_vamb_binny_b3b_omstrup_sillebotten_sediment_norefinem.sh: Bins from both assembly approaches were then dereplicated together with dRep to generate the final species-level MAGs. 

Folder scripts/CoverM:
coverm_oms_sib_sediment_norefinem_drep.sh: The relative abundance of each of the 330 species-level representative MAGs retained after dereplication was estimated in each sample using CoverM.

Folder scripts/GTDB-Tk:
gtdbtk_species_omstrup_sediment_norefinem.sh: Dereplicated MAGs from the Ormstrup sediment samples were taxonomically classified using the GTDB-Tk classify_wf workflow.
gtdbtk_species_sillebotten_sediment_norefinem.sh: Dereplicated MAGs from the Sillebotten sediment samples were taxonomically classified using the GTDB-Tk classify_wf workflow.

Folder scripts:
oms_sib_map: This R script was used to generate the map.
